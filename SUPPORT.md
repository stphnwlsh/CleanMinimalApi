# Support

## Getting help

- **Using the template:** start with the [README](README.md) and [docs/RUN.md](docs/RUN.md).
- **Found a bug?** Open a [bug report](https://github.com/stphnwlsh/CleanMinimalApi/issues/new?template=bug_report.yml).
- **Have an idea?** Open a [feature request](https://github.com/stphnwlsh/CleanMinimalApi/issues/new?template=feature_request.yml).
- **Found a security vulnerability?** Don't open an issue. Follow the [security policy](SECURITY.md).

This is a personal open source project maintained in my spare time, so responses are best effort.

## Supporting the project

If this template is useful to you, please consider [sponsoring me on GitHub](https://github.com/sponsors/stphnwlsh). Sponsorship helps me keep all five templates current with each .NET release.
