# Support

## Getting help

- **Using the template:** start with the [docs site](https://leanmeancleanapps.github.io/minimalapi/), then the [README](README.md) and [docs/RUN.md](docs/RUN.md). They're long because they answer the questions people actually ask.
- **Found a bug?** Open a [bug report](https://github.com/stphnwlsh/CleanMinimalApi/issues/new?template=bug_report.yml). A clear title and a way to reproduce it will get you a faster answer than a long story.
- **Have an idea?** Open a [feature request](https://github.com/stphnwlsh/CleanMinimalApi/issues/new?template=feature_request.yml).
- **Found a security vulnerability?** Don't open an issue. Follow the [security policy](SECURITY.md).

This is a [Lean Mean Clean Apps](https://leanmeancleanapps.github.io/) project, looked after in spare time by a team that is currently one person with a day job and a coffee habit, so responses are best effort. They do arrive.

## Supporting the project

If this template saves you some time, please consider [sponsoring the work on GitHub](https://github.com/sponsors/stphnwlsh). It keeps all five Lean Mean Clean Apps templates current with each .NET release, and the coffee flowing.
